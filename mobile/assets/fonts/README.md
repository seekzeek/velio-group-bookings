Font files go here and are referenced from pubspec.yaml.

Download the variable or static TTFs from Google Fonts and name them:

- BricolageGrotesque-SemiBold.ttf, BricolageGrotesque-Bold.ttf
- Manrope-Regular.ttf, Manrope-Medium.ttf, Manrope-SemiBold.ttf, Manrope-Bold.ttf

Both are licensed under the SIL Open Font License. Until the files are present, Flutter falls back to the platform font.
